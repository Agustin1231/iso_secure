🔒 Seguridad Implementada
  • JWT Stateless — Validado via Supabase REST en cada request
  • Bearer Token — Inyeccion automatica via Axios interceptor
  • CORS Middleware — Origenes controlados en FastAPI
  • Dependency Injection — Auth como dependencia FastAPI
  • HTTP 401/403 — Respuestas automaticas si token invalido
🏢 Multi-tenant Filtering
  • admin / auditor — Ven datos de TODAS las empresas
  • supervisor / analista — Solo datos de SU empresa_id
  • _empresa_filter() — Helper en cada router
  • WHERE clause — Aplicado automaticamente en SQL
  • Row-level isolation — Datos separados por organizacion
